Pusat Unduh Laporan Rekapitulasi (CSV)
Semua file ekspor menyertakan metadata waktu unduh dan filter aktif dalam berkas

Pilih salah satu format laporan di bawah untuk mengunduh rekapan data dalam format file CSV standar yang siap dibuka di Microsoft Excel, Google Sheets, atau sistem HRIS internal.

1. Rekap Keseluruhan

Ringkasan KPI tingkat kehadiran, jumlah hadir, tidak hadir, izin, sakit, dinas, dan hari kerja berlaku.

2. Rekap Setiap Karyawan

Daftar baris per karyawan: hari kerja berlaku, hadir, sakit, izin, terlambat, dan persentase kehadiran.

3. Rekap Harian

Rincian total kehadiran, ketidakhadiran, keterlambatan, dan libur yang diagregasi per tanggal kalender.

4. Rekap Bulanan

Agregasi per bulan (YYYY-MM) beserta persentase kehadiran dan tren keterlambatan bulanan.

5. Rekap per Jabatan/Posisi

Perbandingan kehadiran, ketidakhadiran, dan kedisiplinan yang dikelompokkan menurut posisi pekerjaan.

6. Rekap per Unit Kerja / Divisi

Agregasi per unit kerja atau departemen untuk memantau performa kehadiran antar divisi.

7. Rekap Keterlambatan & Pulang Awal

Log catatan kejadian presensi khusus yang berstatus Terlambat atau Pulang Awal beserta jam aktual.

8. Data Perlu Ditinjau

Ekspor catatan yang memiliki status tidak dikenali atau format anomali untuk peninjauan admin.

Kebijakan Perhitungan Presensi Organisasi
Sesuaikan aturan bisnis kehadiran dan analisis kedisiplinan
Hitung Dinas Luar sebagai Kehadiran (Hadir)

Jika aktif, catatan dengan status "Dinas Luar" akan dihitung sebagai kehadiran efektif dalam perhitungan persentase kehadiran: (Hadir + Dinas Luar) / Hari Kerja.

Gabungkan "Melebihi Toleransi" ke dalam Kategori "Terlambat"

Sesuai ketentuan, "Melebihi Toleransi" secara default ditampilkan sebagai kategori aslinya. Aktifkan opsi ini jika ingin menggabungkannya ke statistik keterlambatan.

Manajemen Cadangan Data (Backup & Restore)
Cadangkan atau pulihkan seluruh database IndexedDB secara aman

Karena aplikasi bekerja 100% di browser Anda tanpa server eksternal, Anda disarankan mengunduh file cadangan JSON secara berkala agar dapat dipindahkan ke perangkat lain atau dipulihkan sewaktu-waktu.

Pusat Pengujian Otomatis & Validasi Ketentuan Teknis
Pengujian khusus untuk memastikan seluruh skenario edge cases ditangani dengan tepat

Sesuai instruksi teknis, modul ini menguji secara mendalam skenario: (1) Pengecualian status Hari Libur dari penyebut hari kerja, (2) Penanganan waktu masuk/keluar berupa tanda - sebagai unavailable, (3) Karyawan dengan beberapa catatan presensi, (4) Deteksi & deduplikasi data duplikat, serta (5) Penanganan status tidak dikenali ke kategori Perlu Ditinjau.
